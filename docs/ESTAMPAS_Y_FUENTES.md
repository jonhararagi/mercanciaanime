# Estampas y fuentes de referencia

El catálogo sirve para mostrar ideas y recibir consultas. Las imágenes enlazadas desde Wikimedia Commons son referencias externas: **no están descargadas en el repositorio y no se garantiza que estén autorizadas para fabricar o vender prendas**. Las condiciones de Wikimedia para alojar un archivo no necesariamente autorizan el uso comercial de marcas, personajes o elementos protegidos por otros derechos.

## Recomendación para vender sin exponerse innecesariamente

- La web es un catálogo de consulta, **no una autorización legal para vender merchandising de anime**.
- Antes de producir o publicar a la venta un logo, personaje, emblema o marca de una franquicia, comprobá los derechos aplicables en Argentina y obtené la licencia/autorización correspondiente cuando sea necesaria.
- Una licencia o etiqueta de dominio público de un archivo gráfico no necesariamente elimina derechos de marca, diseños, personajes u otros derechos de terceros.
- Para una opción de menor riesgo, ofrecé diseños propios (tipografía original, símbolos inventados y composiciones propias) o artes con licencia comercial documentada.
- El campo de texto personalizado solo recoge lo que pide el cliente; escribir un nombre como “Jujutsu Kaisen” o “Bleach” no convierte el logo oficial en un diseño autorizado.
- Confirmá por mensaje disponibilidad, precio final, ubicación de estampa, tiempos y entrega antes de aceptar el pedido.

Este documento es orientación práctica, no asesoramiento jurídico. Si vas a comercializar diseños de franquicias, consultá a un profesional sobre el caso concreto.
